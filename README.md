# CallsignLookup

Aplikacija koja omogućava radioamaterima da pretraže i provjere radioamaterske callsign-ove preko više interneta dostupnih baza podataka.

## Opis

CallsignLookup je desktop aplikacija za Windows koja omogućava brzu i jednostavnu pretragu radioamaterskih callsign-ova. Aplikacija provjerava identitet radioamaterskog callsign-a kroz nekoliko poznatih vanjskih izvora podataka, što čini verificiranje i pronalaženje informacija o radioamaterima brzim i pouzdanim.

## Pretražuje
- QRZ
- QRZCQ
- HamQTH
- Callook

## Značajke

- 🔍 Pretraga po radioamaterskom callsign-u
- 🌐 Integracija s više baza podataka (QRZ, Callook, HamQTH, itd.)
- 📊 Prikaz detaljnih informacija o callsign-u
- 💾 Podrška za DXCC bazu podataka
- 🎯 Jednostavno i intuitivno korisničko sučelje

## Preduvjeti

- Windows 10 ili novije
- .NET 10.0 runtime

## Instalacija

1. Preuzmite najnoviju verziju aplikacije
2. Pokrenite `CallsignLookup.exe`

## Korištenje

1. Otvorite aplikaciju
2. Učitajte ADIF ili LOG datoteku
3. Klikni pretraga
